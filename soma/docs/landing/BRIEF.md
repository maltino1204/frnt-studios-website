THE MISSION

We will create a completely new, exceptional landing page for SOMA.

SOMA is a premium beauty and wellness marketplace connecting customers with independent professionals who deliver treatments directly to their homes, hotels and offices.

Brand: SOMA
Tagline: Your body. Your place.
Descriptor: Beauty & Wellness, wherever you are.

Our objective is to create a world-class digital brand experience that combines sophisticated visual storytelling, exceptional interactions and seamless conversion into the existing SOMA application.

This must look and feel like a premium international lifestyle brand with a highly capable digital product behind it.

Do not create a generic startup landing page.

Go exceptionally professional, editorial, immersive and sophisticated.

1. CRITICAL REFERENCE WEBSITE

Study this website in depth:

https://theoneagency.de/

This reference is extremely important.

Use it as inspiration for the ambition, structural sophistication and technical capabilities of the landing page.

Analyze:

* Overall information architecture
* Chapter-based storytelling
* Section progression
* Interactive navigation
* Hero interactions
* Motion design
* Scroll-driven transitions
* Full-screen compositions
* Creative transitions between sections
* Interactive visual elements
* Layered content
* Responsive behavior
* Mobile interaction patterns
* Microinteractions
* Performance-conscious implementation

Pay particular attention to how the website turns scrolling and navigation into an intentional, engaging experience rather than presenting ordinary stacked content sections.

Understand the interaction principles and recreate a comparable level of craftsmanship with original implementation and art direction.

IMPORTANT RESTRICTION

DO NOT copy the visual identity of theoneagency.de.

Do not copy its:

* Colors
* Fonts
* Logo
* Branding
* Graphic elements
* Copywriting
* Specific layouts
* Media assets
* Proprietary animations or code

Use the reference exclusively for structural inspiration, interaction ambition and technical possibilities.

SOMA must have a completely original design and recognizable brand identity.

2. USE THE EXISTING SOMA BRAND IDENTITY

Before doing anything else, inspect the existing SOMA project.

Locate and read all available brand guidelines, design tokens, logo assets, typography definitions and product documentation.

The SOMA brand identity is the single source of truth.

Do not invent a second design system.

Do not replace previously approved brand assets.

Apply the official SOMA colors, typography, visual language, logo system, imagery principles and motion direction consistently.

The intended visual atmosphere is:

Premium European lifestyle.

Luxury editorial.

Warm architectural minimalism.

Contemporary beauty.

Sensual restraint.

Beautiful typography.

Exceptional attention to detail.

If the brand identity has not yet been implemented, use the following provisional palette:

Bone: #F3EFE8
Stone: #D8CFC3
Taupe: #A69A8D
Oxblood: #542C35
Espresso: #25211F

The approved brand guidelines always take precedence over these fallback values.

3. DESIGN GUIDELINE FIRST

Before implementing the landing page, establish a landing-page-specific design specification derived from the SOMA brand guidelines.

Define:

* Responsive layout grid
* Content widths
* Hero compositions
* Typography scale
* Editorial imagery rules
* Motion behavior
* Scroll behavior
* Navigation mechanics
* Buttons and interactive states
* Section transitions
* Mobile adaptations
* Accessibility behavior

Work from this design specification throughout implementation.

Maintain a single coherent design direction.

Do not create disconnected visual styles between sections.

4. PAGE STRUCTURE

Create a compelling and thoughtfully paced page.

The sections below define the narrative structure, but you are encouraged to improve their composition, interactions and transitions.

SECTION 01 — IMMERSIVE HERO

The opening must immediately establish SOMA as a premium brand.

Use exceptional editorial imagery, elegant display typography and carefully crafted motion.

The main message should communicate that professional beauty and wellness services come directly to the customer.

Suggested headline direction:

Your body. Your place.

Supporting German copy should immediately explain what SOMA does.

The visitor must understand the service within seconds.

Include a beautifully integrated booking entry point.

Ideally, let users specify:

* Desired service
* Location or postal code
* Preferred date

Primary CTA: Jetzt entdecken

Secondary CTA: So funktioniert's

These are starting points; refine the final copy for clarity and conversion.

The booking interface should feel integrated into the premium composition rather than placed inside a generic search widget.

Create one original, memorable hero interaction inspired by the technical ambition of the reference website.

It should reflect the SOMA brand and not exist merely for decoration.

SECTION 02 — THE SOMA PHILOSOPHY

Create an editorial brand statement.

Communicate the idea that personal care should adapt to people's lives, not the other way around.

Use large typography, beautiful spacing, carefully selected imagery and restrained scroll-driven motion.

This should feel like a luxury editorial experience.

Avoid lengthy explanatory paragraphs.

SECTION 03 — SERVICE EXPLORATION

Present the SOMA service universe.

Initial categories:

* Massage
* Nails & Maniküre
* Pediküre
* Kosmetik
* Haare & Styling
* Brows & Lashes
* Make-up

Create an interactive category exploration experience.

Consider large editorial image compositions, elegant hover interactions, kinetic transitions or a carefully controlled horizontal browsing system.

Each category must link to its corresponding marketplace discovery route.

Do not invent destination URLs without checking the existing application routing.

Each service should feel desirable and premium.

SECTION 04 — HOW SOMA WORKS

Explain the process in three intuitive steps:

01 — Entdecken
Finde dein persönliches Treatment.

02 — Buchen
Wähle Ort und Wunschtermin.

03 — Genießen
Dein Professional kommt zu dir.

Create an interactive presentation that is visually sophisticated but immediately understandable.

Avoid generic three-column icon cards.

Explore scroll-linked visual transitions or a polished mobile product walkthrough.

The section should communicate ease, confidence and convenience.

SECTION 05 — THE SOMA EXPERIENCE

Build an immersive section emphasizing the benefits of at-home beauty and wellness.

Use an editorial visual sequence featuring authentic personal care moments and beautiful real-world environments.

Key themes:

* Time saved
* Comfort
* Privacy
* Professional quality
* Personal choice
* Flexible scheduling

Do not invent measurable service guarantees or availability promises.

Make the advantages emotionally compelling through visual storytelling rather than lengthy advertising copy.

SECTION 06 — MEET THE PROFESSIONALS

Present the human side of SOMA.

Create a sophisticated introduction to the professionals behind the platform.

Where real provider data is available, display actual profiles, services and relevant verified information.

If no verified professionals are available, use an explicitly identified design preview or a non-specific brand presentation.

Never invent testimonials, professional qualifications, review counts, provider identities or verification badges.

If functional marketplace data exists, integrate it through the application's existing interfaces.

SECTION 07 — THE DIGITAL EXPERIENCE

Showcase the SOMA application.

Create a premium interactive mobile product presentation.

Use actual SOMA screens, components or realistic previews derived from the existing product.

Consider device mockups, interactive UI demonstrations, controlled scroll transitions and elegant composition.

The result must feel like a compelling product experience rather than a collection of static screenshots.

Do not advertise unreleased features as already available.

SECTION 08 — FOR PROFESSIONALS

Create a dedicated editorial section targeting independent beauty and wellness professionals.

Communicate the benefits of joining SOMA:

* New customer discovery
* Flexible scheduling
* Booking management
* Professional visibility
* Business independence

Provide a clear CTA:

Professional werden

Integrate with the actual provider onboarding route if available.

Avoid unsupported income claims.

SECTION 09 — FAQ & TRUST

Address practical customer questions:

* How does SOMA work?
* Where are services available?
* How are professionals selected?
* How does booking work?
* What happens if an appointment is canceled?
* How does payment work?

Use an elegant, accessible accordion or an equally intuitive interaction pattern.

All operational claims must match the real product.

Do not fabricate trust signals, certifications or policies.

SECTION 10 — FINAL BRAND MOMENT

Close the experience with a memorable, immersive brand statement.

Use exceptional typography, a carefully orchestrated transition and a powerful final composition.

Return to the central message:

SOMA. Your body. Your place.

Include clear calls to action for customers and professionals.

Make the footer visually integrated and meticulously designed.

Include legal links and appropriate navigation.

5. NAVIGATION & INTERACTIONS

Navigation must be a defining part of the experience.

Use theoneagency.de as a reference for what is technically possible.

Explore a custom SOMA chapter navigation system, progress indicator or elegantly animated navigation overlay.

However, do not reproduce the reference site's interaction design literally.

Build something original, intuitive and appropriate for SOMA.

Navigation must provide immediate access to booking at all times.

On mobile, prioritize thumb-friendly controls and avoid interactions that only work with a mouse.

Use deliberate motion, transitions and meaningful feedback throughout.

A visitor should be able to move through the experience effortlessly.

6. VISUAL PRODUCTION

Do not settle for placeholder aesthetics.

Use exceptional, appropriately licensed imagery.

Photography must align with SOMA's art direction:

* Warm
* Editorial
* Human
* Sensual but discreet
* Architectural
* Contemporary
* Authentic

Use real visual assets wherever permitted.

Optimize all images.

Do not hotlink competitor media or reuse competitor-owned assets without permission.

If final imagery is missing, create a documented asset requirement list and use suitable licensed development assets.

Maintain visual coherence across the entire page.

7. MOTION & TECHNICAL EXECUTION

Build an ambitious but performant interactive experience.

Recommended stack:

* Next.js
* TypeScript
* Tailwind CSS
* GSAP and ScrollTrigger for carefully designed advanced animations
* Framer Motion or Motion where suitable
* Existing SOMA components and design tokens

First inspect the current project architecture.

Use existing dependencies wherever appropriate.

Avoid redundant animation libraries and unnecessary client-side JavaScript.

Consider WebGL or React Three Fiber only if a specific interaction genuinely benefits from it.

Do not use 3D simply to make the site look technically impressive.

Prioritize:

* Smooth scrolling without hijacking normal browser behavior
* Refined scene transitions
* Beautiful text reveals
* Subtle image transformations
* Responsive hover and touch interactions
* Intentional loading behavior
* Excellent mobile performance
* Accessible keyboard interactions
* Reduced-motion support

Use progressive enhancement.

The website must remain fully usable if advanced animations fail or are disabled.

8. CONVERSION & APPLICATION INTEGRATION

This is not merely a brand showcase.

The landing page must drive actual marketplace usage.

Every major section should support a clearly defined user intention.

Create elegant, contextual booking opportunities without overwhelming the visual experience.

Connect the hero search and service CTAs to the existing SOMA application.

Preserve search parameters such as service, location and date across navigation where supported.

Avoid unnecessary friction.

Do not require login before basic service discovery unless the existing product architecture requires it.

Ensure that unfinished integrations do not appear functional.

9. SEO & PERFORMANCE

Implement a technically strong marketing website.

Requirements:

* Semantic HTML
* Appropriate metadata
* Open Graph assets
* Structured data where applicable
* Logical heading hierarchy
* Indexable marketing content
* Optimized image delivery
* Responsive assets
* Accessible controls
* Proper internal linking
* Clean URLs
* Good Core Web Vitals

Aim for excellent Lighthouse scores, especially on mobile.

Do not sacrifice usability or performance for unnecessary animation.

Avoid unsupported claims and SEO spam.

10. MULTI-AGENT EXECUTION

You are authorized to coordinate SIX specialized agents under one Lead Agent.

AGENT 1 — REFERENCE & EXPERIENCE RESEARCHER

Analyze theoneagency.de in depth.

Document its structural, interactive and technical principles.

Clearly distinguish transferable interaction ideas from visual or proprietary elements that must not be copied.

AGENT 2 — SOMA ART DIRECTOR

Translate the existing SOMA identity into a detailed landing-page art direction.

Own typography, layout, imagery, composition, visual hierarchy and creative consistency.

AGENT 3 — MOTION & CREATIVE DEVELOPER

Design and implement advanced interactions, scroll-driven scenes, transitions, navigation and microinteractions.

Ensure animations remain smooth, useful and accessible.

AGENT 4 — FRONTEND ENGINEER

Own the primary page implementation.

Build reusable, responsive components and integrate the complete landing page with the existing technical stack.

AGENT 5 — CONVERSION & INTEGRATION SPECIALIST

Own booking entry points, application routing, mobile usability, relevant SEO implementation and conversion mechanics.

AGENT 6 — INDEPENDENT QUALITY AUDITOR

Review all work independently.

Inspect the actual rendered page in desktop, tablet and mobile viewports.

Test interactions, responsiveness, accessibility, navigation, performance and conversion flows.

Evaluate every major dimension from 0 to 10.

All scores must be based on verifiable observations.

LEAD AGENT RESPONSIBILITIES

Coordinate the entire project.

Create a shared implementation plan.

Assign clear ownership.

Prevent file conflicts through separate worktrees or isolated branches where necessary.

Integrate deliverables in stages.

Do not run all agents simultaneously when their tasks have dependencies.

Ensure that the final result remains cohesive.

11. QUALITY STANDARD

The following dimensions must reach at least 8/10:

* Overall visual experience
* Brand fidelity
* Typography and composition
* Interaction design
* Animation quality
* Mobile experience
* User experience
* Conversion clarity
* Technical quality
* Accessibility
* Performance

No superficial reviews.

The independent auditor must inspect the actual implementation.

If constraints prevent an acceptable result, document them accurately rather than inventing passing scores.

Not wireframes.

Not isolated visual prototypes.

Not a static presentation.

The project must include:

* Production-oriented React components
* Responsive layouts
* Functional navigation
* Working interactions
* Brand-compliant styles
* Real application routing where available
* SEO configuration
* Performance optimizations
* Accessible behavior
* Updated documentation
* Final quality audit

Ensure compatibility with the existing GitHub repository and Netlify deployment configuration.

Do not overwrite unrelated product functionality.
